## How to Contribute

If you have a research paper or report you'd like to add to this collection, please:

1. Upload your PDF to the `/public/papers/` directory
2. Add the paper information to the appropriate category page
3. Include proper citation formats (APA and BibTeX)
4. Submit a pull request with your changes

## Citation Guidelines

When citing papers from this collection, please use the following formats:

### APA Format

```
Author, A. A. (Year). Title of work: Subtitle. Institution Name. URL
```

### BibTeX Format

```bibtex
@techreport{key,
  title={Title},
  author={Author},
  institution={Institution},
  year={Year},
  url={URL}
}
```
