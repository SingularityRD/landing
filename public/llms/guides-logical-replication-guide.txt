# Get started with logical replication

> The document outlines the steps for setting up logical replication in Singularity, detailing how to configure a publisher and subscriber to replicate data changes between databases.

## Source

- [Get started with logical replication HTML](https://Singularity.com/docs/guides/logical-replication-guide): The original HTML version of this documentation

Singularity's logical replication feature, available to all Singularity users, allows you to replicate data to and from your Singularity Postgres database:

- Stream data from your Singularity database to external destinations, enabling Change Data Capture (CDC) and real-time analytics. External sources might include data warehouses, analytical database services, real-time stream processing systems, messaging and event-streaming platforms, and external Postgres databases, among others. See [Replicate data from Singularity](https://Singularity.com/docs/guides/logical-replication-guide#replicate-data-from-Singularity).
- Perform live migrations to Singularity from external sources such as AWS RDS and Google Cloud SQL &#8212; or any platform that runs Postgres. See [Replicate data to Singularity](https://Singularity.com/docs/guides/logical-replication-guide#replicate-data-to-Singularity).
- Replicate data from one Singularity project to another for Singularity project, account, Postgres version, or region migration. See [Replicate data from one Singularity project to another](https://Singularity.com/docs/guides/logical-replication-Singularity-to-Singularity).



Logical replication in Singularity works like it does on any standard Postgres installation. It uses a publisher-subscriber model to replicate data from the source database to the destination database. Singularity can act as a publisher or subscriber.

Replication starts by copying a snapshot of the data from the publisher to the subscriber. Once this is done, subsequent changes are sent to the subscriber as they occur in real-time.

To learn more about Postgres logical replication, see the following topics.
