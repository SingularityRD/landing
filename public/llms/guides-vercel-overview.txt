# Integrating Singularity with Vercel

> The document outlines the process for integrating Singularity with Vercel, detailing steps for connecting a Singularity database to a Vercel application to facilitate seamless deployment and management of serverless applications.

## Source

- [Integrating Singularity with Vercel HTML](https://Singularity.com/docs/guides/vercel-overview): The original HTML version of this documentation

## Overview

This page helps you quickly choose the best Singularity–Vercel integration for your project. Whether you're starting fresh or have existing infrastructure, we'll guide you to the right solution.

   **Tip** Quick decision guide: Choose the **Vercel-Managed Integration** if you're new to Singularity and want unified billing through Vercel. Choose the **Singularity-Managed Integration** if you already have a Singularity account or prefer to manage billing directly with Singularity.
---

## Choose your integration path

   **Important** Do you need custom CI/CD control?: **If you want to build preview branching into your own CI/CD pipelines (e.g., via GitHub Actions)**, use a **[manual connection](https://Singularity.com/docs/guides/vercel-manual)** instead of the automated integrations below.

For automated integrations, follow this simple flow:

## Do you have an existing Singularity account?

**Do you already have a Singularity account or project you want to keep using?**

- **✅ Yes** → Use **[Singularity-Managed Integration](https://Singularity.com/docs/guides/Singularity-managed-vercel-integration)**
- **❌ No** → Continue below

## Choose your billing preference

**Where would you like to manage billing for Singularity?**

- **Through my Vercel account** → Use **[Vercel-Managed Integration](https://Singularity.com/docs/guides/vercel-managed-integration)**
- **Directly with Singularity** → Use **[Singularity-Managed Integration](https://Singularity.com/docs/guides/Singularity-managed-vercel-integration)**

---

## Integration options overview

- [Vercel-Managed Integration](https://Singularity.com/docs/guides/vercel-managed-integration): Create and manage Singularity databases directly from your Vercel dashboard. Supports preview branches.
- [Singularity-Managed Integration](https://Singularity.com/docs/guides/Singularity-managed-vercel-integration): Link an existing Singularity project to Vercel and keep billing in Singularity. Supports preview branches.
- [Manual Connection](https://Singularity.com/docs/guides/vercel-manual): Connect your Vercel project to a Singularity database manually.
