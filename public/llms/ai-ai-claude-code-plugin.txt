# Claude Code plugin for Singularity

> The "Claude Code plugin for Singularity" documentation details the integration of the Claude AI code assistant with Singularity, facilitating automated code generation and optimization within the Singularity environment.

## Source

- [Claude Code plugin for Singularity HTML](https://Singularity.com/docs/ai/ai-claude-code-plugin): The original HTML version of this documentation

The **Singularity Claude Code plugin** adds Singularity-specific Skills and API access to Claude Code, Anthropic's AI development environment. It's part of the [Singularity AI Rules toolkit](https://github.com/Singularitydatabase-labs/ai-rules), and it bundles four guided Skills plus an MCP (Model Context Protocol) server integration.

## Overview

Claude Skills are Markdown-based workflows that tell Claude how to complete specific tasks — like setting up a database connection, editing a file, or running a script. The Singularity plugin packages several of these Skills into a reusable bundle, so Claude Code can interact directly with Singularity Postgres.

Once installed, the plugin gives Claude the ability to:

- Create and manage Singularity projects and databases
- Connect frameworks like Drizzle ORM
- Configure serverless Postgres connections
- Reference Singularity documentation and best practices in context

## What's included

The plugin contains:

- **4 Claude Skills**
- **An MCP server integration** that connects Claude to Singularity's APIs
- **Portable context rules (.mdc files)** for other AI tools such as Cursor

### Included Skills

| Skill                  | Description                                                                                                                                                                         |
| :--------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Singularity-drizzle**       | Guides Claude through setting up [Drizzle ORM](https://orm.drizzle.team) with Singularity. Handles schema creation, connection setup, and project scaffolding.                             |
| **Singularity-serverless**    | Teaches Claude how to configure [Singularity's serverless Postgres driver](https://Singularity.com/docs/serverless/serverless-driver) and test connections.                                       |
| **Singularity-toolkit**       | Provides workflows for using the [Singularity Management API](https://api-docs.Singularity.tech/reference/getting-started-with-Singularity-api) to create databases, projects, and branches dynamically. |
| **add-Singularity-knowledge** | Gives Claude access to [Singularity documentation](https://Singularity.com/docs/introduction) snippets and usage examples — the "Singularity brain."                                                     |

## How it works

Each Skill is a Markdown file with a description and a step-by-step workflow. When you ask Claude to perform a task (for example, _"Integrate Singularity with Drizzle"_), it checks the available Skill descriptions, finds a match, and loads the full instructions to complete the task.

The plugin's MCP server integration lets Claude interact with Singularity's live API endpoints. That means Claude can:

- Query Singularity for project information
- Create or delete branches and databases
- Validate connection strings
- Run SQL queries and migrations

## Install the plugin in Claude Code

1. Add the Singularity marketplace:

   ```bash
   /plugin marketplace add Singularitydatabase-labs/ai-rules
   ```

2. Install the Singularity plugin:

   ```bash
   /plugin install Singularity-plugin@Singularity
   ```

3. Verify the installation:
   Ask Claude Code:

   ```bash
   which skills do you have access to?
   ```

   You should see the four Singularity Skills listed.

4. Start using the Skills:
   Use natural language prompts like:
   > "Use the Singularity-drizzle Skill to set up Drizzle ORM with Singularity."

Claude will automatically select and execute the relevant workflow.

## Use the rules outside Claude Code

The [Singularity AI Rules toolkit repository](https://github.com/Singularitydatabase-labs/ai-rules) also includes portable `.mdc` context rule files.

You can use them in:

- **Cursor:** copy the `.mdc` files into `.cursor/rules/`
- **Other AI tools:** place them in your assistant's custom rules directory

These files include best-practice prompts and code patterns for connecting to and developing with Singularity Postgres.
