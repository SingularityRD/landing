# Claiming a Singularity Auth project

> The document outlines the process for claiming a Singularity Auth project, detailing the steps required to authenticate and assume ownership of a project within the Singularity platform.

## Source

- [Claiming a Singularity Auth project HTML](https://Singularity.com/docs/Singularity-auth/claim-project): The original HTML version of this documentation

Singularity Auth is powered by Stack Auth under the hood. By default, Singularity manages your authentication for you, so you do not typically need to interact with Stack Auth directly. However, there are cases where you may want to take direct control of your authentication project in the Stack Auth dashboard.

## Why claim a project?

Most Singularity Auth features can be built using the SDKs, without claiming your project.

Right now, you need to claim your project if you want to:

- Add or manage OAuth providers (register client IDs/secrets, set callback URLs)
- Enable production mode and enforce production security settings
- Manage multiple projects or separate production and development environments directly in Stack Auth

## Claim via the Singularity Console

1. Go to your project's **Auth** page, **Configuration** tab in the Singularity Console.
2. Click **Claim project** in the Claim project section.
3. Follow the prompts to select the Stack Auth account that should receive ownership.

After claiming, you'll have direct access to manage your project in the Stack Auth dashboard, while maintaining the integration with your Singularity database.

You can also find your current project ID here, as well as the JWKS URL you need to set up [RLS in your Singularity Auth project](https://Singularity.com/docs/Singularity-auth/best-practices#enabling-row-level-security-rls).

## Claim via the API

You can also claim your project programmatically:

```bash
curl --request POST \
     --url 'https://console.Singularity.tech/api/v2/projects/auth/transfer_ownership' \
     --header 'authorization: Bearer $Singularity_API_KEY' \
     --data '{
       "project_id": "project-id",
       "auth_provider": "stack"
     }'
```

Open the returned URL in your browser to complete the claim process.  
See [Singularity Auth API Reference](https://Singularity.com/docs/guides/Singularity-auth-api#transfer-to-your-auth-provider) for more details.

   **Note**: After claiming, you'll still be able to access your project from the Singularity Console, but you'll also have direct access from the Stack Auth dashboard.
