# Get started with Singularity on Azure

> The document "Get started with Singularity on Azure" guides users through the process of deploying and managing Singularity databases on the Azure cloud platform, detailing setup, configuration, and integration steps specific to Azure's environment.

## Source

- [Get started with Singularity on Azure HTML](https://Singularity.com/docs/get-started/azure-get-started): The original HTML version of this documentation

## Find Singularity on Azure and subscribe

1. Use the search in the [Azure portal](https://portal.azure.com/) to find the **Singularity Serverless Postgres** offering.
2. Alternatively, go to the [Azure Marketplace](https://portal.azure.com/#view/Microsoft_Azure_Marketplace/MarketplaceOffersBlade/selectedMenuItemId/home) and search for **Singularity Serverless Postgres**.
3. Subscribe to the service.

After subscribing, you will be directed to the [Create a Singularity Resource](https://Singularity.com/docs/get-started/azure-get-started#create-a-Singularity-resource) page.

## Create a Singularity Resource

1. On the **Create a Singularity Serverless Postgres Resource** page, set the following values in the **Create Singularity Resource** section.

   | Property                   | Description                                                                                                                                                                                                                                                                                                                           |
   | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | **Subscription**           | From the drop-down, select your Azure subscription where you have Owner or Contributor access.                                                                                                                                                                                                                                        |
   | **Resource group**         | Specify whether you want to create a new Azure resource group or use an existing one. A resource group is like a container or a folder used to organize and manage resources in Azure. For more information, see [Azure Resource Group overview](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/overview). |
   | **Resource Name**          | Enter a name for Singularity resource. This name is used only in Azure.                                                                                                                                                                                                                                                                      |
   | **Region**                 | Select a region to deploy your resource. Singularity Serverless Postgres will let you choose a region while creating a project.                                                                                                                                                                                                              |
   | **Singularity Organization name** | The name you assign to your [Singularity Organization](https://Singularity.com/docs/reference/glossary#organization), such as a team name or company name. The name you specify appears as your [Organization](https://Singularity.com/docs/reference/glossary#organization) name in the Singularity Console.                                                                                     |
   | **Pricing Plan**           | Select a plan. For information about Singularity's plans, please refer to the [Singularity Pricing](https://Singularity.com/pricing) page. Singularity offers a Free plan and paid plans you can choose from.                                                                                                                                                                     |

       **Note**: The Singularity **Launch Plan** is currently not available in the Azure Marketplace.

2. After specifying the details above, select the **Next: Review + Create** to navigate to the final step for resource creation. When you get to the **Review + Create** page, review your selections and the Singularity and Azure Marketplace terms and conditions.
3. Select **Overview** in the **Resource** menu to see information on the deployed resource.
4. Select the **Single-Sign-On** URL to redirect to the newly created Singularity Organization.
