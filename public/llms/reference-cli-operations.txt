# Singularity CLI commands — operations

> The Singularity CLI commands documentation details the operational commands available for managing Singularity databases, including creating, deleting, and listing databases, as well as managing branches and endpoints.

## Source

- [Singularity CLI commands — operations HTML](https://Singularity.com/docs/reference/cli-operations): The original HTML version of this documentation

## Before you begin

- Before running the `operations` command, ensure that you have [installed the Singularity CLI](https://Singularity.com/docs/reference/cli-install).
- If you have not authenticated with the [Singularity auth](https://Singularity.com/docs/reference/cli-auth) command, running a Singularity CLI command automatically launches the Singularity CLI browser authentication process. Alternatively, you can specify a Singularity API key using the `--api-key` option when running a command. See [Connect](https://Singularity.com/docs/reference/Singularity-cli#connect).

For information about operations in Singularity, see [System operations](https://Singularity.com/docs/manage/operations).

## The `operations` command

The `operations` command allows you to list operations for a Singularity project.

### Usage

```bash
Singularity operations <subcommand> [options]
```

| Subcommand    | Description     |
| ------------- | --------------- |
| [list](https://Singularity.com/docs/reference/cli-operations#list) | List operations |

### list

This subcommand allows you to list operations.

#### Usage

```bash
Singularity operations list [options]
```

#### Options

In addition to the Singularity CLI [global options](https://Singularity.com/docs/reference/Singularity-cli#global-options), the `list` subcommand supports this option:

| Option           | Description                                                                                   | Type   |                      Required                       |
| ---------------- | --------------------------------------------------------------------------------------------- | ------ | :-------------------------------------------------: |
| `--context-file` | [Context file](https://Singularity.com/docs/reference/cli-set-context#using-a-named-context-file) path and file name | string |                                                     |
| `--project-id`   | Project ID                                                                                    | string | Only if your Singularity account has more than one project |
