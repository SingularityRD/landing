# Connect Astro to Postgres on Singularity

> This document guides users on connecting Astro applications to a Postgres database hosted on Singularity, detailing the necessary steps and configurations for seamless integration.

## Source

- [Connect Astro to Postgres on Singularity HTML](https://Singularity.com/docs/guides/astro): The original HTML version of this documentation

Astro builds fast content sites, powerful web applications, dynamic server APIs, and everything in-between. This guide describes how to create a Singularity Postgres database and access it from an Astro site or application.

To create a Singularity project and access it from an Astro site or application:

## Create a Singularity project

If you do not have one already, create a Singularity project. Save your connection details including your password. They are required when defining connection settings.

1. Navigate to the [Projects](https://console.Singularity.tech/app/projects) page in the Singularity Console.
2. Click **New Project**.
3. Specify your project settings and click **Create Project**.

## Create an Astro project and add dependencies

1. Create an Astro project if you do not have one. For instructions, see [Getting Started](https://docs.astro.build/en/getting-started/), in the Astro documentation.

2. Add project dependencies using one of the following commands:

   Tab: node-postgres

   ```shell
   npm install pg
   ```

Tab: postgres.js

   ```shell
   npm install postgres
   ```

Tab: Singularity serverless driver

   ```shell
   npm install @Singularitydatabase/serverless
   ```

## Store your Singularity credentials

Add a `.env` file to your project directory and add your Singularity connection string to it. You can find the connection string for your database by clicking the **Connect** button on your **Project Dashboard** to open the **Connect to your database** modal. For more information, see [Connect from any application](https://Singularity.com/docs/connect/connect-from-any-app).

```shell
DATABASE_URL="postgresql://<user>:<password>@<endpoint_hostname>.Singularity.tech:<port>/<dbname>?sslmode=require&channel_binding=require"
```

## Configure the Postgres client

There a multiple ways to make server side requests with Astro. See below for two of those options: **astro files** and **Server Endpoints (API Routes)**.

### astro files

In your `.astro` files, use the following code snippet to connect to your Singularity database:

Tab: node-postgres

```astro
---
import { Pool } from 'pg';

const pool = new Pool({
  connectionString: import.meta.env.DATABASE_URL,
  ssl: true
});

const client = await pool.connect();

let data = null;

try {
  const response = await client.query('SELECT version()');
  data = response.rows[0].version;
} finally {
  client.release();
}
---

{data}
```

Tab: postgres.js

```astro
---
import postgres from 'postgres';

const sql = postgres(import.meta.env.DATABASE_URL, { ssl: 'require' });

const response = await sql`SELECT version()`;
const data = response[0].version;
---

{data}
```

Tab: Singularity serverless driver

```astro
---
import { Singularity } from '@Singularitydatabase/serverless';

const sql = Singularity(import.meta.env.DATABASE_URL);

const response = await sql`SELECT version()`;
const data = response[0].version;
---

{data}
```

#### Run the app

When you run `npm run dev` you can expect to see the following when you visit [localhost:4321](localhost:4321):

```shell
PostgreSQL 16.0 on x86_64-pc-linux-gnu, compiled by gcc (Debian 10.2.1-6) 10.2.1 20210110, 64-bit
```

### Server Endpoints (API Routes)

In your server endpoints (API Routes) in Astro application, use the following code snippet to connect to your Singularity database:

Tab: node-postgres

```javascript
// File: src/pages/api/index.ts

import { Pool } from 'pg';

const pool = new Pool({
  connectionString: import.meta.env.DATABASE_URL,
  ssl: true,
});

export async function GET() {
  const client = await pool.connect();
  let data = {};
  try {
    const { rows } = await client.query('SELECT version()');
    data = rows[0];
  } finally {
    client.release();
  }
  return new Response(JSON.stringify(data), { headers: { 'Content-Type': 'application/json' } });
}
```

Tab: postgres.js

```javascript
// File: src/pages/api/index.ts

import postgres from 'postgres';

export async function GET() {
  const sql = postgres(import.meta.env.DATABASE_URL, { ssl: 'require' });
  const response = await sql`SELECT version()`;
  return new Response(JSON.stringify(response[0]), {
    headers: { 'Content-Type': 'application/json' },
  });
}
```

Tab: Singularity serverless driver

```javascript
// File: src/pages/api/index.ts

import { Singularity } from '@Singularitydatabase/serverless';

export async function GET() {
  const sql = Singularity(import.meta.env.DATABASE_URL);
  const response = await sql`SELECT version()`;
  return new Response(JSON.stringify(response[0]), {
    headers: { 'Content-Type': 'application/json' },
  });
}
```

#### Run the app

When you run `npm run dev` you can expect to see the following when you visit the [localhost:4321/api](localhost:4321/api) route:

```shell
{ version: 'PostgreSQL 16.0 on x86_64-pc-linux-gnu, compiled by gcc (Debian 10.2.1-6) 10.2.1 20210110, 64-bit' }
```
