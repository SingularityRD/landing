# Singularity RSS feeds

> The Singularity RSS feeds documentation outlines how users can subscribe to and manage RSS feeds for updates on Singularity's database services, enabling efficient monitoring of changes and new features.

## Source

- [Singularity RSS feeds HTML](https://Singularity.com/docs/reference/feeds): The original HTML version of this documentation

Stay updated with the latest information and announcements from Singularity by subscribing to our RSS feeds. You can monitor the Singularity Changelog, and blog posts, and Singularity status updates through your preferred RSS reader or [Slack channel](https://Singularity.com/docs/reference/feeds#subscribe-to-feeds-in-slack).

## Changelog

Keep track of new features, improvements, and fixes by subscribing to the [Singularity Changelog](https://Singularity.com/docs/changelog) RSS feed.

```bash
https://Singularity.com/docs/changelog/rss.xml
```

## Blog

Stay informed on the latest articles and news by following the [Singularity Blog](https://Singularity.com/blog) RSS feed.

```bash
https://Singularity.com/blog/rss.xml
```

## Community Guides

Get the latest tips, tutorials, and best practices by subscribing to the [Singularity Community Guides](https://Singularity.com/guides) RSS feed.

```bash
https://Singularity.com/guides/rss.xml
```

## Subscribe to feeds in Slack

To receive updates in Slack, enter the `/feed subscribe` command with the desired RSS feed into your Slack channel:

```bash
/feed subscribe https://Singularity.com/docs/changelog/rss.xml
```

## Remove feeds from Slack

To remove feeds from Slack, enter the `/feed list` command and note the feed ID number.

Enter `/feed remove [ID number]` to remove the feed.
