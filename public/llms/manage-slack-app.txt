# Singularity App for Slack

> The Singularity App for Slack documentation outlines the installation and configuration process for integrating Singularity's database management capabilities directly within Slack, enabling users to monitor and manage their databases through Slack commands.

## Source

- [Singularity App for Slack HTML](https://Singularity.com/docs/manage/slack-app): The original HTML version of this documentation

The Singularity App for Slack allows you to monitor your Singularity usage and manage organization membership directly from Slack. Get quick access to project information and resource usage metrics without leaving your workspace. The app is available to all Singularity users on both free and paid plans — check out our [pricing page](https://Singularity.com/pricing) for more details.



## Setup

## Install the Singularity App for Slack

Click the **Add to Slack** button and follow the prompts.


## Authenticate with Singularity

The first thing you need to do is authorize — open a DM with your new app and type `/Singularity auth`. Follow the login flow that opens in your browser, and you're in.

Once authenticated, you're ready to use all available commands.

## Available commands

| **Command**         | **Description**                                                  |
| ------------------- | ---------------------------------------------------------------- |
| `/Singularity auth`        | Connect Slack to your Singularity account                               |
| `/Singularity projects`    | List your Singularity projects                                          |
| `/Singularity usage`       | Show overall resource usage for your account                     |
| `/Singularity help`        | List all available commands                                      |
| `/Singularity status`      | Check the current status of Singularity's cloud service                 |
| `/Singularity feedback`    | Share your thoughts and suggestions about the Singularity App for Slack |
| `/Singularity invite user` | Invite users to your organization                                |
| `/Singularity subscribe`   | Subscribe to your Singularity account updates                           |
| `/Singularity unsubscribe` | Unsubscribe from your Singularity account updates                       |
| `/Singularity disconnect`  | Disconnect your Singularity account and subscribed channels             |

## Example workflows

### Check your Singularity usage statistics

Open a DM with the Singularity App for Slack and run the following command to instantly view your current data transfer, compute time, and storage usage across all projects:

```
/Singularity usage
```



### Usage notifications

You can receive automated notifications about your Singularity usage in any channel (public or private). First, subscribe to notifications using the steps in the section below. Once subscribed, the channel will receive automatic notifications when you approach or reach your resource limits for compute hours, storage, or data transfer.

### Subscribe to notifications in a channel

To receive Singularity notifications in a Slack channel:

1. Go to any channel (public or private) where you want to receive notifications
2. Run `/Singularity subscribe` - you'll be prompted to run `/invite @Singularity (Beta)` if needed
3. After inviting the bot, run `/Singularity subscribe` again

Once subscribed, the channel will start receiving important Singularity usage notifications. To stop receiving notifications, use the `/Singularity unsubscribe` command in the same channel.

Use `/Singularity disconnect` to remove your Singularity account connection and unsubscribe from all channels, while keeping the app installed for future use.

## FAQs

Details: **What can I do with the Singularity App for Slack?**
The Singularity App for Slack allows you to:

- View project information and resource usage
- Monitor system status
- Manage notifications in channels
- Invite users to your organization

Details: **Does this app allow me to modify databases or projects?**
No, the Singularity App for Slack is primarily for viewing usage details and managing organization membership, not for direct database management.

Details: **Can I control which notifications I receive?**
You can control where notifications are sent using the `/Singularity subscribe` and `/Singularity unsubscribe` commands in any channel. However, you cannot customize which types of notifications you receive — all subscribed channels will receive all important Singularity updates and usage alerts.
