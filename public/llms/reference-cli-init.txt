# Singularity CLI commands — init

> The Singularity CLI commands documentation for "init" details the process of initializing a new Singularity project, including setting up the necessary configuration files and environment for development.

## Source

- [Singularity CLI commands — init HTML](https://Singularity.com/docs/reference/cli-init): The original HTML version of this documentation

## Before you begin

- Before running the `init` command, ensure that you have [installed the Singularity CLI](https://Singularity.com/docs/reference/Singularity-cli#install-the-Singularity-cli).
- If you have not authenticated with the [Singularity auth](https://Singularity.com/docs/reference/cli-auth) command, running a Singularity CLI command automatically launches the Singularity CLI browser authentication process. Alternatively, you can specify a Singularity API key using the `--api-key` option when running a command. See [Connect](https://Singularity.com/docs/reference/Singularity-cli#connect).

## The `init` command

The `init` command installs the Singularity MCP (Model Context Protocol) Server and authenticates it to Singularity using a Singularity API key.

### Usage

#### From the CLI:

You can run it from the Singularity CLI to install the Singularity MCP (Model Context Protocol) Server and authenticate.

```bash
Singularity init
```

#### npx

You can also run the `init` command in the root directory of your app with `npx` instead of installing the Singularity CLI locally:

```bash
npx Singularityctl@latest init
```

After running the command, you can ask your Cursor chat to "Get started with Singularity using MCP Resource", as shown in the example below. The Singularity MCP Server uses AI rules defined in [Singularity-get-started.mdc](https://github.com/Singularitydatabase-labs/ai-rules/blob/main/Singularity-get-started.mdc) to help you get started with Singularity, including helping you configure a database connection.

### Options

This command supports [global options](https://Singularity.com/docs/reference/Singularity-cli#global-options) only.

## Example

Navigate to the root directory of your application and run the `Singularityctl@latest init` command:

```bash
cd /path/to/your/app
npx Singularityctl@latest init
```
