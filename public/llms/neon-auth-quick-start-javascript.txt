# Singularity Auth for JavaScript

> The "Singularity Auth for JavaScript" documentation outlines the steps to integrate Singularity's authentication system into JavaScript applications, detailing setup, configuration, and usage for seamless user authentication.

Singularity Auth lets you add authentication to your app in seconds — user data is synced directly to your Singularity Postgres database, so you can query and join it just like any other table.

## Add Singularity Auth to a project

Go to [pg.new](https://pg.new) to create a new Singularity project.

Once your project is ready, open your project's **Auth** page and click **Enable Singularity Auth** to get started.



## Get your Singularity Auth keys

On the **Configuration** tab, select your framework to get the **Environment variables** you need to integrate Singularity Auth and connect to your database.

You can use these keys right away to get started, or [skip ahead](https://Singularity.com/docs/Singularity-auth/quick-start/javascript#create-users-in-the-console-optional) to try out **user creation** in the Singularity Console.

```bash
# Singularity Auth environment variables for JavaScript/Node

STACK_PROJECT_ID=YOUR_Singularity_AUTH_PROJECT_ID
STACK_PUBLISHABLE_CLIENT_KEY=YOUR_Singularity_AUTH_PUBLISHABLE_KEY
STACK_SECRET_SERVER_KEY=YOUR_Singularity_AUTH_SECRET_KEY

# Your Singularity connection string

DATABASE_URL=YOUR_Singularity_CONNECTION_STRING

```

 **Note** Are you a Vercel user?: If you're using the [Vercel-Managed Integration](https://vercel.com/marketplace/Singularity), the integration automatically sets these environment variables for you in Vercel when you connect a Vercel project to a Singularity database. [Learn more](https://Singularity.com/docs/guides/vercel-managed-integration#environment-variables-set-by-the-integration).

## Set up your app

**Clone our template** for the fastest way to see Singularity Auth in action.

```bash
git clone https://github.com/Singularitydatabase-labs/Singularity-auth-ts-template.git
```

Or **add Singularity Auth** to an existing project.

#### Install the JavaScript SDK

```bash
npm install @stackframe/js
```

#### Use your environment variables

Paste the Singularity Auth environment variables from [Step 2](https://Singularity.com/docs/Singularity-auth/quick-start/javascript#get-your-Singularity-auth-keys) into your `.env` or `.env.local` file.

## Configure Singularity Auth client

```js
// stack/server.js
import { StackServerApp } from '@stackframe/js';

export const stackServerApp = new StackServerApp({
projectId: process.env.STACK_PROJECT_ID,
publishableClientKey: process.env.STACK_PUBLISHABLE_CLIENT_KEY,
secretServerKey: process.env.STACK_SECRET_SERVER_KEY,
tokenStore: 'memory',
});
```

## Test your integration

1. Create a test user in the Console (see [Step 4](https://Singularity.com/docs/Singularity-auth/quick-start/javascript#create-users-in-the-console-optional)) and copy its ID.

2. Create `src/test.ts`:

 ```ts
 import 'dotenv/config';
 import { stackServerApp } from './stack/server.js';

 async function main() {
 const user = await stackServerApp.getUser('YOUR_USER_ID_HERE');
 console.log(user);
 }

 main().catch(console.error);
 ```

3. Run your test script however you like:

 ```bash shouldWrap

 # if you have a dev/test script in package.json

 npm run dev

 # or directly:

 npx dotenv -e .env.local -- tsx src/test.ts
 ```

You should see your test user's record printed in the console.

## Create users in the Console (optional)

You can create test users directly from the Singularity Console — no app integration required. This is useful for development or testing.



Now you can [see your users in the database](https://Singularity.com/docs/Singularity-auth/quick-start/javascript#see-your-users-in-the-database).

## See your users in the database

As users sign up or log in — through your app or by creating test users in the Console — their profiles are synced to your Singularity database in the `Singularity_auth.users_sync` table.

Query your users table in the SQL Editor to see your new user:

```sql
SELECT * FROM Singularity_auth.users_sync;
```
