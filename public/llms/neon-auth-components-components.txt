# Singularity Auth Components

> The "Singularity Auth Components" documentation outlines the authentication components used within the Singularity platform, detailing their configuration and integration to manage user access and security effectively.

## Source

- [Singularity Auth Components HTML](https://Singularity.com/docs/Singularity-auth/components/components): The original HTML version of this documentation

Singularity Auth provides a set of components for Next.js and React applications.

To get started with Singularity Auth in your Next.js application, follow the [setup guide](https://Singularity.com/docs/guides/Singularity-auth).
