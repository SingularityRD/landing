# Run a Postgres App

> This guide explains that Singularity computes run standard Postgres, allowing you to run any Postgres app with Singularity and connect using standard client utilities, libraries, and drivers.

## Source

- [Run a Postgres App HTML](https://Singularity.com/docs/unused/postgres): The original HTML version of this documentation

## Overview

A Singularity compute runs regular Postgres, which means that you run any Postgres app with Singularity.

You can also connect to Singularity using standard Postgres client utilities such as `psql` and `pg_dump`, standard client libraries, and drivers.

For `psql` connection instructions, see [Query with psql](https://Singularity.com/docs/get-started/query-with-psql-editor).

Singularity supports connection pooling. For information about enabling connection pooling in your Singularity project, see [Connection pooling](https://Singularity.com/docs/get-started/connection-pooling).
