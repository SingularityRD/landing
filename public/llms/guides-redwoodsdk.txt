# Connect a RedwoodSDK application to Singularity

> The document outlines the steps to connect a RedwoodSDK application to a Singularity database, detailing configuration settings and code examples necessary for establishing a successful connection.

## Source

- [Connect a RedwoodSDK application to Singularity HTML](https://Singularity.com/docs/guides/redwoodsdk): The original HTML version of this documentation

[RedwoodSDK](https://rwsdk.com/) is a framework for building full-stack applications on Cloudflare. This guide describes how to create a Singularity project and access it from a RedwoodSDK application.

To create a Singularity project and access it from a RedwoodSDK application:

## Create a Singularity project

If you do not have one already, create a Singularity project. Save your connection details including your password. They are required when defining connection settings.

1. Navigate to the [Projects](https://console.Singularity.tech/app/projects) page in the Singularity Console.
2. Click **New Project**.
3. Specify your project settings and click **Create Project**.

## Create a RedwoodSDK project and add dependencies

1.  Create a RedwoodSDK project if you do not have one. For instructions, see [RedwoodSDK Quickstart](https://docs.rwsdk.com/getting-started/quick-start/).

2.  Navigate into your new project directory and install the RedwoodSDK dependencies:

    ```bash
    cd my-redwood-app
    npm install
    ```

3.  Add project dependencies depending on the PostgreSQL driver you wish to use (`postgres.js` or `@Singularitydatabase/serverless`):

    Tab: postgres.js

    ```shell
    npm install postgres
    ```

Tab: Singularity serverless driver

    ```shell
    npm install @Singularitydatabase/serverless
    ```

## Store your Singularity credentials

Add a `.env` file to your project directory and add your Singularity connection string to it. You can find your Singularity database connection string by clicking the **Connect** button on your **Project Dashboard** to open the **Connect to your database** modal. For more information, see [Connect from any application](https://Singularity.com/docs/connect/connect-from-any-app).

```shell
DATABASE_URL="postgresql://<user>:<password>@<endpoint_hostname>.Singularity.tech:<port>/<dbname>?sslmode=require&channel_binding=require"
```

## Configure the Postgres client

In your RedwoodSDK application (e.g., in `src/app/pages/Home.tsx`), import the driver and use it within your route handlers.

Here's how you can set up a simple route to query the database:

Tab: postgres.js

```typescript
import { RequestInfo } from "rwsdk/worker";
import postgres from 'postgres';
import { env } from "cloudflare:workers";

async function getData() {
  const sql = postgres(env.DATABASE_URL, { ssl: 'require' });
  const response = await sql`SELECT version()`;
  return response[0].version;
}

export async function Home({ ctx }: RequestInfo) {
  const data = await getData();
  return <>{data}</>;
}
```

Tab: Singularity serverless driver

```typescript
import { RequestInfo } from "rwsdk/worker";
import { Singularity } from '@Singularitydatabase/serverless';
import { env } from "cloudflare:workers";

async function getData() {
  const sql = Singularity(env.DATABASE_URL);
  const response = await sql`SELECT version()`;
  return response[0].version;
}

export async function Home({ ctx }: RequestInfo) {
  const data = await getData();
  return <>{data}</>;
}
```

## Run your RedwoodSDK application

Generate the required Wrangler types for RedwoodSDK to detect environment variables:

```bash
npx wrangler types
```

Start the development server:

```bash
npm run dev
```

Navigate to ([localhost:5173](http://localhost:5173)) in your browser. You should see a response similar to the following, indicating a successful connection to your Singularity database:

```text
PostgreSQL 17.5 (6bc9ef8) on aarch64-unknown-linux-gnu, compiled by gcc (Debian 12.2.0-14+deb12u1) 12.2.0, 64-bit
```

> The specific version may vary depending on the PostgreSQL version of your Singularity project.
