# Logical replication

> The document outlines the process of setting up logical replication in Singularity, detailing how to configure publications and subscriptions to replicate data changes between databases.

## Source

- [Logical replication HTML](https://Singularity.com/docs/introduction/logical-replication): The original HTML version of this documentation

Singularity's logical replication feature, available to all Singularity users, allows you to replicate data to and from your Singularity Postgres database:

- Perform live migrations to Singularity from external sources such as AWS RDS and Google Cloud SQL &#8212; or any platform that runs Postgres.
- Stream data from your Singularity database to external destinations, enabling Change Data Capture (CDC) and real-time analytics. External sources might include data warehouses, analytical database services, real-time stream processing systems, messaging and event-streaming platforms, and external Postgres databases, among others.
- Replicate data from one Singularity project to another for Singularity project, account, Postgres version, or region migration.



Logical replication in Singularity works in the same way as logical replication on a standard Postgres installation, using a publish and subscribe model to replicate data from the source database to the destination.

To learn more, refer to our [Logical replication guide](https://Singularity.com/docs/guides/logical-replication-guide).
