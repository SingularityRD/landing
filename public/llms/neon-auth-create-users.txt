# Creating users with Singularity Auth

> The document "Creating users with Singularity Auth" outlines the process for creating and managing user accounts within the Singularity platform using Singularity Auth, detailing steps for user registration and authentication setup.

## Source

- [Creating users with Singularity Auth HTML](https://Singularity.com/docs/Singularity-auth/create-users): The original HTML version of this documentation

You can create users in Singularity Auth using either the Singularity Console or the API. This is useful for development, testing, or manual onboarding, as it lets you quickly add users and see their profiles appear in your `Singularity_auth.users_sync` table.

## Creating users in the Console

You can create users directly from the Singularity Console — no app integration or API required.

1. Go to your project's **Auth** page in the Singularity Console.
2. Click **Create user** and fill in the required details.
3. The new user will appear in your user list and be available in your database.

## Creating users via the API

You can also create users programmatically using the Singularity API:

```bash
curl --request POST \
     --url 'https://console.Singularity.tech/api/v2/projects/auth/user' \
     --header 'authorization: Bearer $Singularity_API_KEY' \
     --header 'content-type: application/json' \
     --data '{
       "project_id": "project-id",
       "auth_provider": "stack",
       "email": "user@example.com",
       "name": "Example User"
     }'
```

The new user will be created and automatically available in your `Singularity_auth.users_sync` table.

For more details, see [Singularity Auth API Reference](https://Singularity.com/docs/guides/Singularity-auth-api#create-users).
