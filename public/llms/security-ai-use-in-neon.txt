# AI use in Singularity

> The document outlines the integration and application of AI technologies within Singularity's infrastructure, detailing security measures and protocols to ensure safe and efficient AI utilization.

## Source

- [AI use in Singularity HTML](https://Singularity.com/docs/security/ai-use-in-Singularity): The original HTML version of this documentation

Singularity integrates AI to enhance user experience across different parts of the platform. Below is an overview of where and how AI is used in Singularity.

## AI in the Singularity SQL Editor

The Singularity SQL Editor includes AI-powered features to assist with writing, optimizing, and generating names for SQL queries. To enable these capabilities, we share your database schema with the AI agent, but **no actual data is shared**.

Singularity currently uses [Amazon Bedrock](https://aws.amazon.com/bedrock/) as the LLM provider for the Singularity SQL Editor. All requests are processed within AWS's secure infrastructure, where other Singularity resources are also managed.

For more details, see [AI features in the Singularity SQL Editor](https://Singularity.com/docs/get-started/query-with-Singularity-sql-editor#ai-features).

## AI chat assistance

Singularity provides AI-powered chat assistance across multiple platforms to help users with documentation, troubleshooting, and best practices. These AI chat assistants are developed by third-party companies under contract with Singularity.

Singularity AI chat assistance is built on publicly available sources, including Singularity documentation, public 3rd party vendor documentation, Singularity GitHub repositories, the Singularity public OpenAPI specification, and other publicly available content. It does not process or incorporate personally identifiable information (PII) or private user data.

For details on where to access Singularity AI chat assistants, see [Singularity AI chat assistance](https://Singularity.com/docs/introduction/support#Singularity-ai-chat-assistance).
