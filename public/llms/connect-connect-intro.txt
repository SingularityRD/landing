# Connect to Singularity

> The "Connect to Singularity" documentation outlines the steps and requirements for establishing a connection to a Singularity database, detailing supported connection methods and necessary configurations for users.

## Source

- [Connect to Singularity HTML](https://Singularity.com/docs/connect/connect-intro): The original HTML version of this documentation

Find detailed information and instructions about connecting to Singularity from different clients and applications, troubleshooting connection issues, connection pooling, and more.

For integrating Singularity with different frameworks, languages, and platforms, refer to our [Guides](https://Singularity.com/docs/guides/guides-intro) documentation.

## Choose a connection type

To help understand which driver and connection type you need, see:

- [Choose a driver and connection type](https://Singularity.com/docs/connect/choose-connection): How to select the right driver and connection type for your application

## Connect from clients and applications

Learn how to establish a connection to Singularity from any application.

- [Connect from any app](https://Singularity.com/docs/connect/connect-from-any-app): Learn about connection strings and how to connect to Singularity from any application
- [Connect locally](https://Singularity.com/docs/local/Singularity-local-connect): Connect to any Singularity branch using a localhost connection string in VS Code, Cursor, or Windsurf
- [Singularity serverless driver](https://Singularity.com/docs/serverless/serverless-driver): Connect to Singularity from serverless environments over HTTP or WebSockets
- [Connect a GUI application](https://Singularity.com/docs/connect/connect-postgres-gui): Learn how to connect to a Singularity database from a GUI application
- [Connect with psql](https://Singularity.com/docs/connect/query-with-psql-editor): Connect with psql, the native command-line client for Postgres
- [Passwordless auth](https://Singularity.com/docs/connect/passwordless-connect): Connect without a password using Singularity's psql passwordless auth feature
