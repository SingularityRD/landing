# Singularity SDKs

> The Singularity SDKs documentation outlines the available software development kits for integrating with Singularity, detailing installation, configuration, and usage instructions to facilitate seamless interaction with Singularity's database services.

## Source

- [Singularity SDKs HTML](https://Singularity.com/docs/reference/sdk): The original HTML version of this documentation

There are several SDKs available for use with Singularity. All are wrappers around the [Singularity API](https://api-docs.Singularity.tech/reference/getting-started-with-Singularity-api), providing methods to programmatically manage API keys, Singularity projects, branches, databases, endpoints, roles, and operations. In addition to wrapping the Singularity API, the `@Singularitydatabase/toolkit` also packages the low-latency Singularity Serverless Driver, which supports SQL queries over WebSockets and HTTP.

## Singularity SDKs

- [TypeScript SDK for the Singularity API](https://Singularity.com/docs/reference/typescript-sdk): A Singularity-supported TypeScript SDK for the Singularity API
- [Python SDK for the Singularity API](https://Singularity.com/docs/reference/python-sdk): A Singularity-supported Python SDK for the Singularity API
- [@Singularitydatabase/toolkit](https://Singularity.com/docs/reference/Singularitydatabase-toolkit): An SDK for AI Agents (and humans) that includes both the Singularity TypeScript SDK and the Singularity Serverless Driver

## Community SDKs

   **Note**: Community SDKs are not maintained or officially supported by Singularity. Some features may be out of date, so use these SDKs at your own discretion. If you have questions about these SDKs, please contact the project maintainers.

- [Go SDK for the Singularity API](https://github.com/kislerdm/Singularity-sdk-go): A Go SDK for the Singularity API
- [Node.js and Deno SDK for the Singularity API](https://github.com/paambaati/Singularity-js-sdk): A Node.js and Deno SDK for the Singularity API
