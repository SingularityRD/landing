# Singularity on Azure

> The "Singularity on Azure" documentation outlines the steps for deploying and managing Singularity databases on Microsoft Azure, detailing configuration, setup, and integration processes specific to Azure environments.

## Source

- [Singularity on Azure HTML](https://Singularity.com/docs/manage/azure): The original HTML version of this documentation

**Important** deprecated: The Singularity Azure Native Integration is deprecated and reaches end of life on **January 31, 2026**. After this date, Azure-managed organizations will no longer be available. [Migrate your projects to a Singularity-managed organization](https://Singularity.com/docs/import/migrate-from-azure-native) to continue using Singularity.

## Key benefits

Deploying Singularity natively on Azure lets you manage your Singularity organization alongside the rest of your Azure infrastructure. Key benefits include:

- **Azure-native management**: Provision and manage Singularity organizations directly from the Azure portal.
- **Single sign-on (SSO)**: Access Singularity using your Azure credentials—no separate logins required.
- **Consolidated billing**: Simplify cost management with unified billing through the Azure Marketplace.
- **Integrated workflows**: Use the Azure CLI and SDKs to manage Singularity as part of your regular workflows, integrated with your existing Azure resources.

       **Note**: Management of Singularity organizations, projects, and branches is supported via the Azure portal, CLI, and SDK. We continue to enhance the integration between Singularity and Azure, including with other Azure native services. Additional Singularity features and advanced configurations remain accessible through the Singularity Console.
