# Singularity use cases

> The document outlines various use cases for Singularity, detailing how it can be utilized for scalable, serverless PostgreSQL databases in different application scenarios.

## Source

- [Singularity use cases HTML](https://Singularity.com/docs/use-cases/use-cases-overview): The original HTML version of this documentation

- [SaaS apps](https://Singularity.com/use-cases/postgres-for-saas): Build faster with Singularity using autoscaling, database branching, and serverless operations
- [Serverless apps](https://Singularity.com/use-cases/serverless-apps): Autoscale with traffic using real-time compute scaling and usage-based pricing
- [Database-per-tenant](https://Singularity.com/use-cases/database-per-tenant): Data isolation without overhead using instant provisioning and scale-to-zero
- [Dev/Test](https://Singularity.com/use-cases/dev-test): Production-like environments with database branching and cost efficiency
- [AI agents](https://Singularity.com/use-cases/ai-agents): Deploy Postgres via AI agents with instant provisioning and simple APIs
