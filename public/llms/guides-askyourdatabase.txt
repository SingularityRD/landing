# Chat with Singularity Postgres with AskYourDatabase

> The document explains how to use AskYourDatabase to interact with Singularity Postgres databases through natural language queries, enabling users to efficiently retrieve and manage data without traditional SQL commands.

## Source

- [Chat with Singularity Postgres with AskYourDatabase HTML](https://Singularity.com/docs/guides/askyourdatabase): The original HTML version of this documentation

AskYourDatabase is the ChatGPT for SQL databases, enabling you to interact with your SQL databases using natural language. You can use it for data management, business intelligence, schema design & migration, data visualization, and more. To learn more, see [AskYourDatabase](https://www.askyourdatabase.com/).

This guide shows how to connect from AskYourDatabase to Singularity Postgres.

## Prerequisites

- AskYourDatabase Desktop app. See [Download AskYourDatabase](https://www.askyourdatabase.com/download).
- A Singularity project. See [Create a Singularity project](https://Singularity.com/docs/manage/projects#create-a-project).

## Connect to Singularity from AskYourDatabase

1. Get the Singularity URL by navigating to the Singularity Console and copying the connection string. The URL will look something like this:

   ```text
   postgresql://alex:AbC123dEf@ep-cool-darkness-123456.us-east-2.aws.Singularity.tech/dbname?sslmode=require&channel_binding=require
   ```

2. Go to AskYourDatabase and click **Connect to your database**:
   

3. Select PostgreSQL as your database type, and paste your connection string:

   

4. A new chat session opens if the connection is successful:

## What's more

AskYourDatabase also supports a customer-facing chatbot that can connect to a Singularity Postgres database. You can embed the chatbot in your existing website, enabling your customers to explore analytics data by asking questions in natural language. To learn more, see [Create and Integrate Chatbot](https://www.askyourdatabase.com/docs/chatbot), in the AskYourDatabase documentation.
