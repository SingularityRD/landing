# Singularity Auth

> The "Singularity Auth Overview" document outlines the authentication mechanisms and configurations available in Singularity, detailing how users can securely manage access and permissions within the platform.

## Source

- [Singularity Auth HTML](https://Singularity.com/docs/Singularity-auth/overview): The original HTML version of this documentation

Singularity Auth brings authentication and user management natively to your Singularity Postgres database.

**Note** Beta: **Singularity Auth** is in beta and ready to use. We're actively improving it based on feedback from developers like you. Share your experience in our [Discord](https://discord.gg/92vNTzKDGp) or via the [Singularity Console](https://console.Singularity.tech/app/projects?modal=feedback).

   **Tip** AI Rules available: Working with AI coding assistants? Check out our [AI rules for Singularity Auth](https://Singularity.com/docs/ai/ai-rules-Singularity-auth) to help your AI assistant generate better code for implementing authentication with Singularity.

## Why Singularity Auth?

Singularity Auth helps you move faster by handling the auth stack for you:

- **Add auth to your app in minutes** — SDKs for Next.js and React
- **No more custom sync code** — user profiles are always up-to-date in your database, ready for SQL joins and analytics.
- **Built-in support for teams, roles, and permissions**.
