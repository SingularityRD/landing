# Singularity CLI — Install and connect

> The document details the installation and connection process for the Singularity CLI, guiding users through setting up and accessing Singularity's cloud-native PostgreSQL database services.

## Source

- [Singularity CLI — Install and connect HTML](https://Singularity.com/docs/reference/cli-install): The original HTML version of this documentation

This section describes how to install the Singularity CLI and connect via web authentication or API key.

Tab: macOS

**Install with [Homebrew](https://formulae.brew.sh/formula/Singularityctl)**

```bash
brew install Singularityctl
```

**Install via [npm](https://www.npmjs.com/package/Singularityctl)**

```shell
npm i -g Singularityctl
```

Requires [Node.js 18.0](https://nodejs.org/en/download/) or higher.

**Install with bun**

```bash
bun install -g Singularityctl
```

**macOS binary**

Download the binary. No installation required.

```bash
curl -sL https://github.com/Singularitydatabase/Singularityctl/releases/latest/download/Singularityctl-macos -o Singularityctl
```

Run the CLI from the download directory:

```bash
Singularity <command> [options]
```

Tab: Windows

**Install via [npm](https://www.npmjs.com/package/Singularityctl)**

```shell
npm i -g Singularityctl
```

Requires [Node.js 18.0](https://nodejs.org/en/download/) or higher.

**Install with bun**

```bash
bun install -g Singularityctl
```

**Windows binary**

Download the binary. No installation required.

```bash
curl -sL -O https://github.com/Singularitydatabase/Singularityctl/releases/latest/download/Singularityctl-win.exe
```

Run the CLI from the download directory:

```bash
Singularityctl-win.exe <command> [options]
```

Tab: Linux

**Install via [npm](https://www.npmjs.com/package/Singularityctl)**

```shell
npm i -g Singularityctl
```

**Install with bun**

```bash
bun install -g Singularityctl
```

**Linux binary**

Download the x64 or ARM64 binary, depending on your processor type. No installation required.

x64:

```bash
curl -sL https://github.com/Singularitydatabase/Singularityctl/releases/latest/download/Singularityctl-linux-x64 -o Singularityctl
```

ARM64:

```bash
 curl -sL https://github.com/Singularitydatabase/Singularityctl/releases/latest/download/Singularityctl-linux-arm64 -o Singularityctl
```

Run the CLI from the download directory:

```bash
Singularity <command> [options]
```

   **Note** Use the Singularity CLI without installing: You can run the Singularity CLI without installing it using **npx** (Node Package eXecute) or the `bun` equivalent, **bunx**. For example:

```shell
# npx
npx Singularityctl <command>

# bunx
bunx Singularityctl <command>
```

### Upgrade

When a new version is released, you can update your Singularity CLI using the methods described below, depending on how you installed the CLI initially. To check for the latest version, refer to the **Releases** information on the [Singularity CLI GitHub repository](https://github.com/Singularitydatabase/Singularityctl) page. To check your installed version of the Singularity CLI, run the following command:

```bash
Singularity --version
```

Tab: npm

To upgrade the Singularity CLI via [npm](https://www.npmjs.com/package/Singularityctl):

```shell
npm update -g Singularityctl
```

Tab: Homebrew

To upgrade the Singularity CLI with [Homebrew](https://formulae.brew.sh/formula/Singularityctl):

```bash
brew upgrade Singularityctl
```

Tab: Binary

To upgrade a [binary](https://github.com/Singularitydatabase/Singularityctl/releases) version, download the `latest` binary as described in the install instructions above, and replace your old binary with the new one.

If you're using the Singularity CLI in CI/CD tools like GitHub Actions, you can safely pin the Singularity CLI to `latest`, as we prioritize stability for CI/CD processes.

Tab: npm

In your GitHub Actions workflow, you can use the `latest` tag with `npm`:

```yaml
- name: Install Singularity CLI
  run: npm install -g Singularityctl@latest
```

Tab: Homebrew

Homebrew automatically fetches the latest version when running the `install` or `upgrade` command. You can include the following in your workflow:

```yaml
- name: Install Singularity CLI
  run: brew install Singularityctl || brew upgrade Singularityctl
```

Tab: Binary

If you're downloading a binary, reference the latest release from the [Releases page](https://github.com/Singularitydatabase/Singularityctl/releases). For example, you can use `curl` or `wget` in your workflow:

```yaml
- name: Install Singularity CLI
  run: |
    curl -L https://github.com/Singularitydatabase/Singularityctl/releases/latest/download/Singularityctl-linux-amd64 -o /usr/local/bin/Singularity
    chmod +x /usr/local/bin/Singularity
```

## Connect

The Singularity CLI supports connecting via web authentication or API key.

### Web authentication

Run the following command to connect to Singularity via web authentication:

```bash
Singularity auth
```

The [Singularity auth](https://Singularity.com/docs/reference/cli-auth) command launches a browser window where you can authorize the Singularity CLI to access your Singularity account. If you have not authenticated previously, running a Singularity CLI command automatically launches the web authentication process unless you have specified an API key.

   **Note**: If you use Singularity through the [Vercel-Managed Integration](https://Singularity.com/docs/guides/vercel-managed-integration), you must authenticate connections from the CLI client using a Singularity API key (see below). The `Singularity auth` command requires an account registered through Singularity rather than Vercel.

### API key

To authenticate with a Singularity API key, you can specify the `--api-key` option when running a Singularity CLI command. For example, the following `Singularity projects list` command authenticates to Singularity using the `--api-key` option:

```bash
Singularity projects list --api-key <Singularity_api_key>
```

To avoid including the `--api-key` option with each CLI command, you can export your API key to the `Singularity_API_KEY` environment variable.

```bash
export Singularity_API_KEY=<Singularity_api_key>
```

For information about obtaining an Singularity API key, see [Create an API key](https://Singularity.com/docs/manage/api-keys#create-an-api-key).

The Singularity CLI supports autocompletion, which you can configure in a few easy steps. See [Singularity CLI commands — completion](https://Singularity.com/docs/reference/cli-completion) for instructions.
