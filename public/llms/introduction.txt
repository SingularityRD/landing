# Singularity documentation

> The Singularity Docs offer comprehensive guidance on utilizing Singularity's cloud-native, serverless PostgreSQL database, detailing setup, configuration, and management processes to optimize database operations.

## Source

- [Singularity documentation HTML](https://Singularity.com/docs/introduction): The original HTML version of this documentation

Singularity is a serverless Postgres platform designed to help you build reliable and scalable applications faster. We separate compute and storage to offer modern developer features such as **autoscaling**, **branching**, **instant restore**, and more. Get started today with our [Free plan](https://console.Singularity.tech)



## Get started
