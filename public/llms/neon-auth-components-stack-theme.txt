# <StackTheme />

> The `<StackTheme />` documentation outlines the implementation details and usage of the StackTheme component within Singularity's authentication system, detailing its role in managing theme configurations for consistent UI styling.

## Source

- [<StackTheme /> HTML](https://Singularity.com/docs/Singularity-auth/components/stack-theme): The original HTML version of this documentation

A component that applies a theme to its children.

For more information, see the [color and styles guide](https://Singularity.com/docs/Singularity-auth/customization/custom-styles).

## Props

- `theme` (optional): `ThemeConfig` — Custom theme configuration to override the default theme.
- `children` (optional): `React.ReactNode` — Child components to be rendered within the themed context.

## Example

```tsx
const theme = {
  light: {
    primary: 'red',
  },
  dark: {
    primary: '#00FF00',
  },
  radius: '8px',
}

// ...

<StackTheme theme={theme}>
  {/* children */}
</StackTheme>
```
