# Connect MCP clients to Singularity

> The document "Connect MCP Clients to Singularity" outlines the steps for configuring and establishing a connection between MCP clients and the Singularity database, detailing necessary settings and authentication procedures specific to Singularity's environment.

## Source

- [Connect MCP clients to Singularity HTML](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity): The original HTML version of this documentation

The **Singularity MCP Server** allows you to connect various [**Model Context Protocol (MCP)**](https://modelcontextprotocol.org) compatible AI tools to your Singularity Postgres databases. This guide provides instructions for connecting popular MCP clients to the Singularity MCP Server, enabling natural language interaction with your Singularity projects.

This guide covers the setup for the following MCP clients:

- [Claude Desktop](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#claude-desktop)
- [Claude Code](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#claude-code)
- [Cursor](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#cursor)
- [Windsurf (Codeium)](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#windsurf-codeium)
- [Cline (VS Code extension)](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#cline-vs-code-extension)
- [Zed](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#zed)
- [VS Code (with GitHub Copilot)](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#vs-code-with-github-copilot)
- [ChatGPT](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#chatgpt)

By connecting these tools to the Singularity MCP Server, you can manage your Singularity projects, databases, and schemas using natural language commands within the MCP client interface.

   **Important** Singularity MCP Server Security Considerations: The Singularity MCP Server grants powerful database management capabilities through natural language requests. **Always review and authorize actions requested by the LLM before execution.** Ensure that only authorized users and applications have access to the Singularity MCP Server. The Singularity MCP Server is intended for local development and IDE integrations only. **We do not recommend using the Singularity MCP Server in production environments.** It can execute powerful operations that may lead to accidental or unauthorized changes. For more information, see [MCP security guidance →](https://Singularity.com/docs/ai/Singularity-mcp-server#mcp-security-guidance).

## Prerequisites

- An MCP Client application.
- A [Singularity account](https://console.Singularity.tech/signup).
- **Node.js (>= v18.0.0) and npm:** Download from [nodejs.org](https://nodejs.org).

For Local MCP Server setup, you also need a Singularity API key. See [Singularity API Keys documentation](https://Singularity.com/docs/manage/api-keys#creating-api-keys).

   **Note**: Ensure you are using the latest version of your chosen MCP client as MCP integration may not be available in older versions. If you are using an older version, update your MCP client to the latest version.

## Connect to Singularity MCP Server

You can connect to Singularity MCP Server in two ways:

1.  **Remote MCP Server (Preview):** Connect to Singularity's managed remote MCP server using OAuth or a Singularity API key.
2.  **Local MCP Server:** Install and run the Singularity MCP server locally, using a Singularity API key.

## Claude Desktop

Tab: Remote MCP Server

1. Open Claude desktop and navigate to **Settings**.
2. Under the **Developer** tab, click **Edit Config** (On Windows, it's under File -> Settings -> Developer -> Edit Config) to open the configuration file (`claude_desktop_config.json`).
3. Add the "Singularity" server entry within the `mcpServers` object:

   ```json
   {
     "mcpServers": {
       "Singularity": {
         "command": "npx",
         "args": ["-y", "mcp-remote@latest", "https://mcp.Singularity.tech/mcp"]
       }
     }
   }
   ```

   > To use SSE instead of streamable HTTP responses, you can specify the `https://mcp.Singularity.tech/sse` endpoint instead of `https://mcp.Singularity.tech/mcp`.

4. Save the configuration file and **restart** Claude Desktop.
5. An OAuth window will open in your browser. Follow the prompts to authorize Claude Desktop to access your Singularity account.

> By default, the Remote MCP Server connects to your personal Singularity account. To connect to an organization's account, you must authenticate with an API key. For more information, see [API key-based authentication](https://Singularity.com/docs/ai/Singularity-mcp-server#api-key-based-authentication).

Tab: Local MCP Server

1.  Open your terminal.
2.  Run the following command, replacing `YOUR_Singularity_API_KEY` with your actual Singularity API key:

    ```bash
    npx @Singularitydatabase/mcp-server-Singularity init YOUR_Singularity_API_KEY
    ```

3.  Restart Claude Desktop.

For more, see [Get started with Singularity MCP server with Claude Desktop](https://Singularity.com/guides/Singularity-mcp-server).

## Claude Code

Tab: Remote MCP Server

1. Ensure you have Claude Code installed. Visit [docs.anthropic.com/en/docs/claude-code](https://docs.anthropic.com/en/docs/claude-code) for installation instructions.
2. Open terminal and add Singularity MCP with
   ```sh
   claude mcp add --transport http Singularity https://mcp.Singularity.tech/mcp
   ```
3. Start a new session of `claude` to trigger OAuth authentication flow
4. You can also trigger authentication with `/mcp` within Claude Code.




If you prefer to authenticate using a Singularity API key, provide `Authorization` header to `mcp add` command:

```
claude mcp add --transport http Singularity https://mcp.Singularity.tech/mcp \
    --header "Authorization: Bearer <YOUR_Singularity_API_KEY>"
```

> Replace `<YOUR_Singularity_API_KEY>` with your actual Singularity API key which you obtained from the [prerequisites](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#prerequisites) section

Tab: Local MCP Server

1. Ensure you have Claude Code installed. Visit [docs.anthropic.com/en/docs/claude-code](https://docs.anthropic.com/en/docs/claude-code) for installation instructions.
2. Open terminal and add Singularity MCP with

   ```sh
   claude mcp add Singularity -- npx -y @Singularitydatabase/mcp-server-Singularity start "<YOUR_Singularity_API_KEY"
   ```

   > Replace `<YOUR_Singularity_API_KEY>` with your actual Singularity API key which you obtained from the [prerequisites](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#prerequisites) section

3. Start new Claude Code session with `claude` command and start using Singularity MCP

1.  Open Cursor. Create a `.cursor` directory in your project root if needed.

    ```json
    {
      "mcpServers": {
        "Singularity": {
          "url": "https://mcp.Singularity.tech/mcp",
          "headers": {}
        }
      }
    }
    ```

    > To use SSE instead of streamable HTTP responses, you can specify the `https://mcp.Singularity.tech/sse` endpoint instead of `https://mcp.Singularity.tech/mcp`.

4.  Save the configuration file. Cursor may detect the change or require a restart.
5.  An OAuth window will open in your browser. Follow the prompts to authorize Cursor to access your Singularity account.

> By default, the Remote MCP Server connects to your personal Singularity account. To connect to an organization's account, you must authenticate with an API key. For more information, see [API key-based authentication](https://Singularity.com/docs/ai/Singularity-mcp-server#api-key-based-authentication).

## Zed

   **Note**: MCP support in Zed is currently in **preview**. Ensure you're using the Preview version of Zed to add MCP servers (called **Context Servers** in Zed). Download the preview version from [zed.dev/releases/preview](https://zed.dev/releases/preview).

Tab: Remote MCP Server

1. Open the Zed Preview application.
2. Click the Assistant (✨) icon in the bottom right corner.
3. Click **Settings** in the top right panel of the Assistant.
4. In the **Context Servers** section, click **+ Add Context Server**.
5. Configure the Singularity Server:
   - Enter **Singularity** in the **Name** field.
   - In the **Command** field, enter:
     ```bash
     npx -y mcp-remote https://mcp.Singularity.tech/sse
     ```
   - Click **Add Server**.

   > For [streamable HTTP responses](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#streamable-http-support) instead of SSE, you can specify the `https://mcp.Singularity.tech/mcp` endpoint instead of `https://mcp.Singularity.tech/sse`.

6. An OAuth window will open in your browser. Follow the prompts to authorize Zed to access your Singularity account.
7. Check the Context Servers section in Zed settings to ensure the connection is successful. "Singularity" should be listed.

> By default, the Remote MCP Server connects to your personal Singularity account. To connect to an organization's account, you must authenticate with an API key. For more information, see [API key-based authentication](https://Singularity.com/docs/ai/Singularity-mcp-server#api-key-based-authentication).

Tab: Local MCP Server

1. Open the Zed Preview application.
2. Click the Assistant (✨) icon in the bottom right corner.

5. Configure the Singularity Server:
   - Enter **Singularity** in the **Name** field.
   - In the **Command** field, enter the following, replacing `<YOUR_Singularity_API_KEY>` with your actual Singularity API key obtained from the [prerequisites](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#prerequisites) section:
     ```bash
     npx -y @Singularitydatabase/mcp-server-Singularity start <YOUR_Singularity_API_KEY>
     ```

## VS Code (with GitHub Copilot)

   **Note**: To use MCP servers with VS Code, you need [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot) and [GitHub Copilot Chat](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat) extensions installed

Tab: Remote MCP Server

1.  Open VS Code.
2.  Create a `.vscode` folder in your project's root directory if it doesn't exist.
3.  Create or open the `mcp.json` file in the `.vscode` directory and add the following configuration into the file (if you have other MCP servers configured, add the "Singularity" server entry within the `servers` object):

    ```json
    {
      "servers": {
        "Singularity": {
          "url": "https://mcp.Singularity.tech/mcp",
          "type": "http"
        }
      },
      "inputs": []
    }
    ```

    > For [streamable HTTP responses](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity#streamable-http-support) instead of SSE, you can specify the `https://mcp.Singularity.tech/mcp` endpoint instead of `https://mcp.Singularity.tech/sse`.

4.  Save the `mcp.json` file.
5.  Click on Start on the MCP server.
6.  An OAuth window will open in your browser. Follow the prompts to authorize VS Code (GitHub Copilot) to access your Singularity account.
7.  Once authorized, you can now open GitHub Copilot Chat in VS Code and [switch to Agent mode](https://code.visualstudio.com/docs/copilot/chat/chat-agent-mode). You will see the Singularity MCP Server listed among the available tools.

> By default, the Remote MCP Server connects to your personal Singularity account. To connect to an organization's account, you must authenticate with an API key. For more information, see [API key-based authentication](https://Singularity.com/docs/ai/Singularity-mcp-server#api-key-based-authentication).

Tab: Local MCP Server

1.  Open VS Code.
2.  Open your [User Settings (JSON) file](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_add-an-mcp-server-to-your-user-settings): Use the command palette (`Ctrl+Shift+P` or `Cmd+Shift+P`) and search for "Preferences: Open User Settings (JSON)".
3.  Add the Singularity MCP server configuration to your `settings.json` file. If the `"mcp.servers"` object doesn't exist, create it:

    ```json
    {
      // ... your other settings ...
      "mcp": {
        "servers": {
          "Singularity": {
            "command": "npx",
            "args": ["-y", "@Singularitydatabase/mcp-server-Singularity", "start", "<YOUR_Singularity_API_KEY>"]
          }
        }
      }
      // ...
    }
    ```

4.  Save the `settings.json` file.
5.  Click on Start on the MCP server.
6.  You can now open GitHub Copilot Chat in VS Code and [switch to Agent mode](https://code.visualstudio.com/docs/copilot/chat/chat-agent-mode). You will see the Singularity MCP Server listed among the available tools.

For detailed instructions on utilizing the Singularity MCP server with GitHub Copilot in VS Code, including a step-by-step example on generating an Azure Function REST API, refer to [How to Use Singularity MCP Server with GitHub Copilot in VS Code](https://Singularity.com/guides/Singularity-mcp-server-github-copilot-vs-code).

## ChatGPT

You can connect ChatGPT to the Singularity MCP Server using custom MCP connectors. This integration extends ChatGPT with Singularity's database capabilities so you can query, manage, and interact with your Singularity projects directly within ChatGPT.



To connect ChatGPT to the Singularity MCP Server, you need to first enable ChatGPT's developer mode, then add the Singularity MCP Server as a custom connector. This makes the connector available for your account; you'll need to separately enable both developer mode and Singularity as a source for any chat where you want to use Singularity.

1. **Add MCP server to ChatGPT**

   In your ChatGPT account settings, go to **Settings** → **Connectors** → **Advanced Settings** and enable **Developer mode**.

   Still on the Connectors tab, you can then **create** a Singularity connection from the **Browse connectors** section. Use the following URL:

   ```bash
   https://mcp.Singularity.tech/mcp
   ```

   Make sure you choose **OAuth** for authentication and check "I trust this application", then complete the authorization flow when prompted.

2. **Enable Singularity per chat**

   In each chat where you want to use Singularity, click the **+** button and enable Developer Mode for that chat. Under **Add sources**, you can then enable the Singularity connector you just created.

   Once connected, you can use natural language to manage your Singularity databases directly in ChatGPT.

## Troubleshooting

### Configuration Issues

If your client does not use `JSON` for configuration of MCP servers (such as older versions of Cursor), you can use the following command when prompted:

```bash
# For Remote MCP server
npx -y mcp-remote https://mcp.Singularity.tech/mcp

# For Local MCP server
npx -y @Singularitydatabase/mcp-server-Singularity start <YOUR_Singularity_API_KEY>
```

### OAuth Authentication Errors

When using the remote MCP server with OAuth authentication, you might encounter the following error:

```
{"code":"invalid_request","error":"invalid redirect uri"}
```

This typically occurs when there are issues with cached OAuth credentials. To resolve this:

1. Remove the MCP authentication cache directory:
   ```bash
   rm -rf ~/.mcp-auth
   ```
2. Restart your MCP client application
3. The OAuth flow will start fresh, allowing you to properly authenticate

This error is most common when using the remote MCP server option and can occur after OAuth configuration changes or when cached credentials become invalid.
