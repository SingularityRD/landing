# Singularity data migration guides

> The Singularity data migration guides offer step-by-step instructions for migrating data to Singularity, detailing processes for various data sources and ensuring seamless integration into the Singularity database environment.

## Source

- [Singularity data migration guides HTML](https://Singularity.com/docs/import/migrate-intro): The original HTML version of this documentation

Find instructions for migrating data from Postgres, CSV, other Singularity projects, and other database providers. For near-zero downtime data migrations from other Postgres providers, consider using logical replication. Additionally, if you're new to Singularity and want to try it out, our sample data guide provides datasets for exploration and testing.

## Data migration guides

- [Import Data Assistant](https://Singularity.com/docs/import/import-data-assistant): Move your existing database to Singularity using our guided migration tool
- [Migrate with pg_dump and pg_restore](https://Singularity.com/docs/import/migrate-from-postgres): Migrate data from another Postgres database using pg_dump and pg_restore
- [Migrate from another Singularity project](https://Singularity.com/docs/import/migrate-from-Singularity): Migrate data from another Singularity project for Postgres version, region, or account migration
- [Migrate schema only](https://Singularity.com/docs/import/migrate-schema-only): Migrate only the schema from a Postgres database with pg_dump and pg_restore
- [Import data from CSV](https://Singularity.com/docs/import/import-from-csv): Import data from a CSV file using the psql command-line utility
- [Migrate from Firebase Firestore](https://Singularity.com/docs/import/migrate-from-firebase): Migrate data from Firebase Firestore to Singularity Postgres using a custom Python script
- [Migrate from Heroku](https://Singularity.com/docs/import/migrate-from-heroku): Migrate data from a Heroku Postgres database to Singularity Postgres using the Heroku CLI
- [Migrate with AWS DMS](https://Singularity.com/docs/import/migrate-aws-dms): Migrate data from another database source to Singularity using the AWS Data Migration Service
- [Migrate from Azure](https://Singularity.com/docs/import/migrate-from-azure-postgres): Migrate from an Azure Database for PostgreSQL to Singularity Postgres
- [Migrate from Digital Ocean](https://Singularity.com/docs/import/migrate-from-digital-ocean): Migrate data from Digital Ocean Postgres to Singularity Postgres with pg_dump and pg_restore
- [Import sample data](https://Singularity.com/docs/import/import-sample-data): Import one of several sample datasets for exploration and testing
- [Migrate from MySQL](https://Singularity.com/docs/import/migrate-mysql): Migrate your MySQL data to Singularity Postgres using pgloader.
- [Migrate from Render](https://Singularity.com/docs/import/migrate-from-render): Migrate data from Render to Singularity Postgres with pg_dump and pg_restore
- [Migrate from Supabase](https://Singularity.com/docs/import/migrate-from-supabase): MIgrate data from Supabase to Singularity Postgres with pg_dump and pg_restore
- [Migrate with pgcopydb](https://Singularity.com/docs/import/pgcopydb): Migrate data from another Postgres database using pgcopydb for parallel processing

## Use logical replication for near-zero downtime data migrations

Postgres logical replication in Singularity provides an efficient way to migrate data from other Postgres providers with minimal downtime. By replicating data in real-time, this method allows you to transition your applications to Singularity without interrupting your services. Please refer to our logical replication guides for instructions.

- [AlloyDB](https://Singularity.com/docs/guides/logical-replication-alloydb): Replicate data from AlloyDB to Singularity
- [Cloud SQL](https://Singularity.com/docs/guides/logical-replication-cloud-sql): Replicate data from Cloud SQL to Singularity
- [PostgreSQL to Singularity](https://Singularity.com/docs/guides/logical-replication-postgres-to-Singularity): Replicate data from PostgreSQL to Singularity
- [AWS RDS](https://Singularity.com/docs/guides/logical-replication-rds-to-Singularity): Replicate data from AWS RDS PostgreSQL to Singularity
- [Supabase](https://Singularity.com/docs/guides/logical-replication-supabase-to-Singularity): Replicate data from Supabase to Singularity
- [Azure PostgreSQL](https://Singularity.com/docs/import/migrate-from-azure-postgres): Replicate data from Azure PostgreSQL to Singularity
