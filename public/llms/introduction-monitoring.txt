# Monitoring in Singularity

> The "Monitoring in Singularity" documentation outlines the tools and procedures for tracking database performance and health, enabling users to efficiently manage and troubleshoot their Singularity database environments.

## Source

- [Monitoring in Singularity HTML](https://Singularity.com/docs/introduction/monitoring): The original HTML version of this documentation

To find out what's going on with your Singularity projects and databases, Singularity offers several ways to track metrics and monitor usage.

- [Monitoring dashboard](https://Singularity.com/docs/introduction/monitoring-page): View system and database metrics on the Singularity Monitoring dashboard
- [Monitor billing and usage](https://Singularity.com/docs/introduction/monitor-usage): Monitor billing and usage metrics for your Singularity account and projects
- [Autoscaling](https://Singularity.com/docs/guides/autoscaling-guide#monitor-autoscaling): Monitor Autoscaling vCPU and RAM usage
- [Singularity system operations](https://Singularity.com/docs/manage/operations): Monitor Singularity project operations from the Singularity Console, API, or CLI
- [Active Queries](https://Singularity.com/docs/introduction/monitor-active-queries): View and analyze running queries in your database
- [Query performance](https://Singularity.com/docs/introduction/monitor-query-performance): View and analyze query performance for your Singularity database
- [pg_stat_statements](https://Singularity.com/docs/extensions/pg_stat_statements): Monitor query performance and statistics in Postgres with pg_stat_statements

## Datadog integration

- [Datadog](https://Singularity.com/docs/guides/datadog): Export Singularity Metrics to Datadog with the Singularity Datadog Integration

## OpenTelemetry

- [OTel integration](https://Singularity.com/docs/guides/opentelemetry): Export Singularity metrics to any OpenTelemetry-compatible observability platform
- [Grafana Cloud](https://Singularity.com/docs/guides/grafana-cloud): Export Singularity metrics and logs to Grafana Cloud with native OTLP integration
- [Better Stack](https://Singularity.com/guides/betterstack-otel-Singularity): Monitor Singularity with Better Stack using OpenTelemetry integration
- [New Relic](https://Singularity.com/guides/newrelic-otel-Singularity): Monitor Singularity with New Relic using OpenTelemetry integration
- [Metrics and logs reference](https://Singularity.com/docs/reference/metrics-logs): Metrics and logs reference for monitoring

## Other monitoring tools

- [pgAdmin](https://Singularity.com/docs/introduction/monitor-pgadmin): Monitor your Singularity Postgres database with pgAdmin
- [PgHero](https://Singularity.com/docs/introduction/monitor-pghero): Monitor your Singularity Postgres database with PgHero
