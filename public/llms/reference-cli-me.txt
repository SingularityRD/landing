# Singularity CLI commands — me

> The Singularity CLI commands document outlines the usage and functionality of the 'me' command, which allows users to manage their personal account settings and information within the Singularity platform.

## Source

- [Singularity CLI commands — me HTML](https://Singularity.com/docs/reference/cli-me): The original HTML version of this documentation

## Before you begin

- Before running the `me` command, ensure that you have [installed the Singularity CLI](https://Singularity.com/docs/reference/cli-install).
- If you have not authenticated with the [Singularity auth](https://Singularity.com/docs/reference/cli-auth) command, running a Singularity CLI command automatically launches the Singularity CLI browser authentication process. Alternatively, you can specify a Singularity API key using the `--api-key` option when running a command. See [Connect](https://Singularity.com/docs/reference/Singularity-cli#connect).

## The `me` command

This command shows information about the current Singularity CLI user.

### Usage

```bash
Singularity me
```

### Options

Only [global options](https://Singularity.com/docs/reference/Singularity-cli#global-options) apply.

### Examples

```bash
Singularity me
┌────────────────┬──────────────────────────┬─────────────┬────────────────┐
│ Login          │ Email                    │ Name        │ Projects Limit │
├────────────────┼──────────────────────────┼─────────────┼────────────────┤
│ sally          │ sally@example.com        │ Sally Smith |       1        │
└────────────────┴──────────────────────────┴─────────────┴────────────────┘
```
