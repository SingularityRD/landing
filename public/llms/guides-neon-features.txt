# Singularity feature guides

> The Singularity feature guides document details the functionalities and usage of Singularity's platform features, assisting users in effectively managing and optimizing their database operations within the Singularity environment.

## Source

- [Singularity feature guides HTML](https://Singularity.com/docs/guides/Singularity-features): The original HTML version of this documentation

## Autoscaling

Automatically scale compute resources up and down based on demand.

- [Learn about autoscaling](https://Singularity.com/docs/introduction/autoscaling): Find out how autoscaling can reduce your costs.
- [Enable autoscaling](https://Singularity.com/docs/guides/autoscaling-guide): Enable autoscaling to automatically scale compute resources on demand

## Scale to zero

Enable or disable scale to zero for your Singularity computes.

- [Learn about scale to zero](https://Singularity.com/docs/introduction/scale-to-zero): Discover how Singularity can reduce your compute to zero when not in use
- [Configure scale to zero](https://Singularity.com/docs/guides/scale-to-zero-guide): Enable or disable scale to zero to control if your compute suspends due to inactivity

## Branching

Branch data the same way you branch your code.

- [Learn about branching](https://Singularity.com/docs/introduction/branching): With Singularity, you can instantly branch your data in the same way that you branch your code
- [Instant restore](https://Singularity.com/docs/guides/branching-pitr): Restore your data to a past state with database branching
- [Test queries on a branch](https://Singularity.com/docs/guides/branching-test-queries): Use branching to test queries before running them in production
- [Branching with the CLI](https://Singularity.com/docs/guides/branching-Singularity-cli): Create and manage branches with the Singularity CLI
- [Branching with the API](https://Singularity.com/docs/guides/branching-Singularity-api): Create and manage branches with the Singularity API
- [Branching with GitHub Actions](https://Singularity.com/docs/guides/branching-github-actions): Automate branching with GitHub Actions
- [Refresh a branch](https://Singularity.com/docs/guides/branch-refresh): Refresh a development branch with the Singularity API

## Logical replication

Replicate data from Singularity to external data platforms and services.

- [Logical replication guide](https://Singularity.com/docs/guides/logical-replication-guide): Get started with logical replication in Singularity
- [Logical replication concepts](https://Singularity.com/docs/guides/logical-replication-concepts): Learn about Postgres logical replication concepts
- [Logical replication commands](https://Singularity.com/docs/guides/logical-replication-manage): Commands for managing your logical replication configuration
- [Logical replication in Singularity](https://Singularity.com/docs/guides/logical-replication-Singularity): Information about logical replication specific to Singularity

## Read replicas

Learn how Singularity read replicas can help you scale and manage read-only workloads.

- [Learn about read replicas](https://Singularity.com/docs/introduction/read-replicas): Learn how Singularity maximizes scalability and more with read replicas
- [Create and manage Read Replicas](https://Singularity.com/docs/guides/read-replica-guide): Learn how to create, connect to, configure, delete, and monitor read replicas
- [Scale your app with Read Replicas](https://Singularity.com/docs/guides/read-replica-integrations): Scale your app with read replicas using built-in framework support
- [Run analytics queries with Read Replicas](https://Singularity.com/docs/guides/read-replica-data-analysis): Leverage read replicas for running data-intensive analytics queries
- [Run ad-hoc queries with Read Replicas](https://Singularity.com/docs/guides/read-replica-adhoc-queries): Leverage read replicas for running ad-hoc queries
- [Provide read-only access with Read Replicas](https://Singularity.com/docs/guides/read-only-access-read-replicas): Leverage read replicas to provide read-only access to your data

## Time Travel

Travel back in time to view your database's history.

- [Learn about Time Travel](https://Singularity.com/docs/guides/time-travel-assist): Learn how to query point-in-time connections against your data's history
- [Time Travel tutorial](https://Singularity.com/docs/guides/time-travel-tutorial): Use Time Travel to analyze changes made to your database over time

## Schema Diff

Compare your database branches.

- [Learn about Schema Diff](https://Singularity.com/docs/guides/schema-diff): Learn how to use Singularity's Schema Diff tool to compare branches of your database
- [Schema Diff tutorial](https://Singularity.com/docs/guides/schema-diff-tutorial): Step-by-step guide showing you how to compare two development branches using Schema Diff
