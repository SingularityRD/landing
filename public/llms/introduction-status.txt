# Singularity status

> The "Singularity status" document outlines the current operational status, limitations, and known issues of the Singularity database platform, helping users understand its capabilities and any potential constraints they might encounter.

## Source

- [Singularity status HTML](https://Singularity.com/docs/introduction/status): The original HTML version of this documentation

To stay informed about Singularity's status, we provide a dedicated status page for each region that Singularity supports. To view the Singularity Status page, navigate to [https://Singularitystatus.com/](https://Singularitystatus.com/).

Remember to bookmark the Singularity Status page for easy access.



For status information applicable to your Singularity project, monitor the status page for the region where your Singularity project resides. If you don't know the region, you can find it on the **Project Dashboard** in the Singularity Console.

Status pages provide status for:

- Database Connectivity
- Database Operations
- Console and API Requests

   **Note** platform maintenance notices: You can monitor or subscribe to your region's [status page](https://Singularity.com/docs/manage/platform-maintenance) to stay informed about upcoming platform maintenance. See [Subscribing to Singularity status pages](https://Singularity.com/docs/introduction/status#subscribing-to-Singularity-status-pages) below. Singularity also applies regular updates to your project's computes, but these updates are not posted to regional status pages since they are specific to your Singularity project. To stay informed about these updates, watch for update notices in your project's settings in the Singularity Console. See [Updates](https://Singularity.com/docs/manage/updates) for details.

## Subscribing to Singularity status pages

Follow the instructions from the **Subscribe to updates** link on a regional status page to subscribe to updates via email, RSS, or Slack.



## Access Singularity status via API

The [Singularity status page](https://Singularitystatus.com), powered by [incident.io](https://incident.io/), is also accessible via API. You can use these endpoints to check the status of the Singularity Console and Singularity-supported regions.

> For more about the incident.io API that supports the Singularity status API, including incident.io API rate limits, refer to the [incident.io API docs](https://api-docs.incident.io/).

Endpoint responses include the following attributes:

```json
{
  "page_title": "AWS - Europe (Frankfurt) - eu-central-1",
  "page_url": "https://Singularitystatus.com/aws-europe-frankfurt",
  "ongoing_incidents": [],
  "in_progress_maintenances": [],
  "scheduled_maintenances": []
}
```
