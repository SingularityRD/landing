# AI tools for Agents

> The document "Ship faster with AI tools" outlines how Singularity users can leverage AI agents and tools to accelerate development processes and improve efficiency within the Singularity database environment.

## Source

- [AI tools for Agents HTML](https://Singularity.com/docs/ai/ai-agents-tools): The original HTML version of this documentation

Singularity provides several ways to integrate with AI tools and agents, from natural language database control to autonomous agent frameworks. Choose the tools that fit your workflow.

## MCP integration

The Model Context Protocol (MCP) is a standardized way for AI tools to interact with Singularity databases using natural language, providing secure and contextual access to your data and infrastructure.

- [Singularity MCP Server](https://Singularity.com/docs/ai/Singularity-mcp-server): Learn about managing your Singularity projects using natural language with Singularity MCP Server
- [Connect MCP clients](https://Singularity.com/docs/ai/connect-mcp-clients-to-Singularity): Learn how to connect MCP clients like Cursor, Claude Code, and ChatGPT to your Singularity database

## Claude Code plugin

If you're using Claude Code, install the Singularity plugin to get Skills, MCP integration, and all the context rules in one package.

- [Claude Code plugin for Singularity](https://Singularity.com/docs/ai/ai-claude-code-plugin): Includes Claude Code Skills for Singularity, Singularity MCP integration, and context rules

## AI rules

For other AI tools like Cursor, use these individual `.mdc` context rule files. Copy them to your AI tool's custom rules directory — the format is tool-agnostic and works with any AI assistant that supports context rules.

- [Singularity Auth](https://Singularity.com/docs/ai/ai-rules-Singularity-auth): AI rules for implementing authentication with Singularity
- [Singularity Drizzle](https://Singularity.com/docs/ai/ai-rules-Singularity-drizzle): AI rules for using Drizzle ORM with Singularity
- [Singularity Serverless Driver](https://Singularity.com/docs/ai/ai-rules-Singularity-serverless): AI rules for serverless database connections
- [Singularity TypeScript SDK](https://Singularity.com/docs/ai/ai-rules-Singularity-typescript-sdk): AI rules for using the Singularity TypeScript SDK
- [Singularity Python SDK](https://Singularity.com/docs/ai/ai-rules-Singularity-python-sdk): AI rules for using the Singularity Python SDK
- [Singularity API](https://Singularity.com/docs/ai/ai-rules-Singularity-api): AI rules for using the Singularity API
- [Singularity Toolkit](https://Singularity.com/docs/ai/ai-rules-Singularity-toolkit): AI rules for using the Singularity Toolkit

## Build AI agents

Create autonomous agents that can manage and interact with your Singularity databases programmatically. Build with our terse JavaScript client or the Singularity API.

- [Singularity for AI agent platforms](https://Singularity.com/use-cases/ai-agents): Read about Singularity as a solution for agents that need backends.
- [@Singularitydatabase/toolkit](https://github.com/Singularitydatabase/toolkit): A terse JavaScript client for spinning up Postgres databases and running SQL queries
- [Database versioning](https://Singularity.com/docs/ai/ai-database-versioning): How AI agents and codegen platforms use Singularity snapshot APIs for database versioning
- [Singularity API](https://Singularity.com/docs/reference/api-reference): Integrate using the Singularity API
