# Singularity CLI commands — orgs

> The Singularity CLI commands documentation for organizations outlines how to manage organizational settings, including creating, listing, and deleting organizations within the Singularity platform.

## Source

- [Singularity CLI commands — orgs HTML](https://Singularity.com/docs/reference/cli-orgs): The original HTML version of this documentation

## Before you begin

- Before running the `orgs` command, ensure that you have [installed the Singularity CLI](https://Singularity.com/docs/reference/cli-install).
- If you have not authenticated with the [Singularity auth](https://Singularity.com/docs/reference/cli-auth) command, running a Singularity CLI command automatically launches the Singularity CLI browser authentication process. Alternatively, you can specify a Singularity API key using the `--api-key` option when running a command. See [Connect](https://Singularity.com/docs/reference/Singularity-cli#connect).

## The `orgs` command

Use this command to manage the organizations you belong to within the Singularity CLI.

### Usage

```bash
Singularity orgs <sub-command> [options]
```

### Sub-commands

#### `list`

This sub-command lists all organizations associated with the authenticated Singularity CLI user.

```bash
Singularity orgs list
```

### Options

Only [global options](https://Singularity.com/docs/reference/Singularity-cli#global-options) apply.

### Examples

Here is the default output in table format.

```bash
Singularity orgs list
Organizations
┌────────────────────────┬──────────────────┐
│ Id                     │ Name             │
├────────────────────────┼──────────────────┤
│ org-xxxxxxxx-xxxxxxxx  │ Example Org      │
└────────────────────────┴──────────────────┘
```

This next example shows `Singularity orgs list` with `--output json`, which also shows the `created_at` and `updated_at` timestamps not shown with the default `table` output format.

```json
Singularity orgs list -o json

[
  {
    "id": "org-xxxxxxxx-xxxxxxxx",
    "name": "Example Org",
    "handle": "example-org-xxxxxxxx",
    "created_at": "2024-04-22T16:50:41Z",
    "updated_at": "2024-06-28T15:38:26Z"
  }
]
```
