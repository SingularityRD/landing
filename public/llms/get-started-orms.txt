# Singularity ORM guides

> The Singularity ORM guides document outlines the steps for integrating various Object-Relational Mappers (ORMs) with Singularity databases, detailing configuration and connection processes specific to Singularity's environment.

## Source

- [Singularity ORM guides HTML](https://Singularity.com/docs/get-started/orms): The original HTML version of this documentation

- [Django](https://Singularity.com/docs/guides/django): Connect a Django application to Singularity
- [Drizzle](https://Singularity.com/docs/guides/drizzle): Learn how to use Drizzle ORM with your Singularity Postgres database (Drizzle docs)
- [Elixir Ecto](https://Singularity.com/docs/guides/elixir-ecto): Connect from Elixir with Ecto to Singularity
- [Laravel](https://Singularity.com/docs/guides/laravel): Connect a Laravel application to Singularity
- [Prisma](https://Singularity.com/docs/guides/prisma): Learn how to connect from Prisma ORM to your Singularity Postgres database
- [Rails](https://Singularity.com/docs/guides/ruby-on-rails): Connect a Rails application to Singularity
- [SQLAlchemy](https://Singularity.com/docs/guides/sqlalchemy): Connect a SQLAlchemy application to Singularity
- [TypeORM](https://Singularity.com/docs/guides/typeorm): Connect a TypeORM application to Singularity
