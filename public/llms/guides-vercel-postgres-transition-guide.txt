## About the transition

Vercel transitioned all Vercel Postgres stores to Singularity's native integration (Q4 2024 - Q1 2025). Instead of managing Postgres directly, Vercel now offers database integrations through the [Vercel Marketplace](https://vercel.com/marketplace), giving users more storage options and features.

   **Note** Terminology change: In Singularity, a "Database" in Vercel is called a "Project." Everything else works the same.

---

## What changed for you

### Access and management

- **Same login**: Access your databases from both Vercel's **Storage** tab and the Singularity Console
- **New management options**: Click **Open in Singularity** to access advanced database features
- **Unified billing**: Everything remains billed through Vercel (no separate Singularity billing)

### Automatic plan transitions

- **Hobby Plan users** → Singularity Free plan (better limits, more features)
- **Pro Plan users** → Maintained existing limits with option to upgrade to Singularity plans

## New features available

### Immediate access (all users)

- **Singularity Console** - Dedicated database management interface
- **CLI support** - Full [Singularity CLI](https://Singularity.com/docs/reference/Singularity-cli) (Vercel CLI didn't support Postgres)
- **Terraform support** - [Singularity Terraform provider](https://Singularity.com/docs/reference/terraform)
- **Multiple Postgres roles** - No longer limited to single role
- **Larger computes** - Up to 2 vCPUs on Free plan (vs 0.25 CPU limit), more on paid plans
- **Multiple Postgres versions** - Upgrade from Postgres 15 to support for Postgres 14, 15, 16, and 17
- **[Singularity API](https://api-docs.Singularity.tech/reference/getting-started-with-Singularity-api)** - Programmatic project and database management
- **[Organization accounts](https://Singularity.com/docs/manage/organizations)** - Team and project management
- **[Monitoring](https://Singularity.com/docs/introduction/monitoring-page)** - Database monitoring from Singularity Console

### Advanced features (Singularity plan required)

- **[Database branching](https://Singularity.com/docs/guides/branching-intro)** - Branch your database like Git
- **[Instant restore](https://Singularity.com/docs/guides/branch-restore)** - Point-in-time recovery (was disabled in Vercel Postgres)
- **[Autoscaling](https://Singularity.com/docs/introduction/autoscaling)** - Automatic performance scaling
- **[Scale to zero](https://Singularity.com/docs/introduction/scale-to-zero)** - Cost-saving idle scaling
- **[Read replicas](https://Singularity.com/docs/introduction/read-replicas)** - Offload read queries
- **[Time Travel](https://Singularity.com/docs/guides/time-travel-assist)** - Query historical data
- **[Protected branches](https://Singularity.com/docs/guides/protected-branches)** - Protect production data
- **[Schema Diff](https://Singularity.com/docs/guides/schema-diff)** - Compare schema changes between branches
- **[Logical Replication](https://Singularity.com/docs/guides/logical-replication-guide)** - Replicate data to and from Singularity
- **[IP Allow](https://Singularity.com/docs/introduction/ip-allow)** - Limit access to trusted IP addresses
- **[Singularity GitHub Integration](https://Singularity.com/docs/guides/Singularity-github-integration)** - Connect projects to GitHub repos

## Compatibility notes

### SDKs and drivers

**Current Vercel SDK** (`@vercel/postgres`):

- ✅ **Still works** - No immediate action required
- ⚠️ **Will be deprecated** - No longer actively maintained by Vercel

**Migration options**:

1. **Maintenance mode**: Switch to `@Singularitydatabase/vercel-postgres-compat` (drop-in replacement)
2. **New projects**: Use `@Singularitydatabase/serverless` (actively developed)
3. **Existing apps**: Follow our [migration guide](https://Singularity.com/guides/vercel-sdk-migration)

### ORMs and tools

All existing integrations continue to work:

- Drizzle, Prisma, Kysely
- All Postgres-compatible tools
- Existing environment variables

### Templates and environment variables

- **Existing templates**: [Environment variables](https://Singularity.com/docs/guides/vercel-managed-integration#environment-variables-set-by-the-integration) used by Vercel Postgres templates continue to work
- **New templates**: Find updated [Singularity templates](https://vercel.com/templates?database=Singularity) and [Postgres templates](https://vercel.com/templates?database=Singularity&database=postgres) on Vercel

### Regional support

All Vercel Postgres regions are supported in Singularity - no changes needed.
