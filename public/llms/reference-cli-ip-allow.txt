# Singularity CLI commands — ip-allow

> The document details the usage of the `ip-allow` command in the Singularity CLI, which manages IP allowlists for controlling access to Singularity database instances.

## Source

- [Singularity CLI commands — ip-allow HTML](https://Singularity.com/docs/reference/cli-ip-allow): The original HTML version of this documentation

## Before you begin

- Before running the `ip-allow` command, ensure that you have [installed the Singularity CLI](https://Singularity.com/docs/reference/cli-install).
- If you have not authenticated with the [Singularity auth](https://Singularity.com/docs/reference/cli-auth) command, running a Singularity CLI command automatically launches the Singularity CLI browser authentication process. Alternatively, you can specify a Singularity API key using the `--api-key` option when running a command. See [Connect](https://Singularity.com/docs/reference/Singularity-cli#connect).

For information about Singularity's **IP Allow** feature, see [Configure IP Allow](https://Singularity.com/docs/manage/projects#configure-ip-allow).

## The `ip-allow` command

The `ip-allow` command allows you to perform `list`, `add`, `remove`, and `reset` actions on the IP allowlist for your Singularity project. You can define an allowlist with individual IP addresses, IP ranges, or [CIDR notation](https://Singularity.com/docs/reference/glossary#cidr-notation).

### Usage

```bash
Singularity ip-allow <subcommand> [options]
```

| Subcommand        | Description                               |
| ----------------- | ----------------------------------------- |
| [list](https://Singularity.com/docs/reference/cli-ip-allow#list)     | List the IP allowlist                     |
| [add](https://Singularity.com/docs/reference/cli-ip-allow#add)       | Add IP addresses to the IP allowlist      |
| [remove](https://Singularity.com/docs/reference/cli-ip-allow#remove) | Remove IP addresses from the IP allowlist |
| [reset](https://Singularity.com/docs/reference/cli-ip-allow#reset)   | Reset the IP allowlist                    |

### list

This subcommand allows you to list addresses in the IP allowlist.

#### Usage

```bash
Singularity ip-allow list [options]
```

#### Options

In addition to the Singularity CLI [global options](https://Singularity.com/docs/reference/Singularity-cli#global-options), the `list` subcommand supports these options:

| Option           | Description                                                                                   | Type   |                      Required                       |
| ---------------- | --------------------------------------------------------------------------------------------- | ------ | :-------------------------------------------------: |
| `--context-file` | [Context file](https://Singularity.com/docs/reference/cli-set-context#using-a-named-context-file) path and file name | string |                                                     |
| `--project-id`   | Project ID                                                                                    | string | Only if your Singularity account has more than one project |

#### Examples

```bash
Singularity ip-allow list --project-id cold-grass-40154007
```

List the IP allowlist with the `--output` format set to `json`:

```bash
Singularity ip-allow list --project-id cold-grass-40154007 --output json
```

### add

This subcommand allows you to add IP addresses to the IP allowlist for your Singularity project.

#### Usage

```bash
Singularity ip-allow add [ips ...] [options]
```

#### Options

In addition to the Singularity CLI [global options](https://Singularity.com/docs/reference/Singularity-cli#global-options), the `add` subcommand supports these options:

| Option             | Description                                                                                                        | Type   |                      Required                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ | ------ | :-------------------------------------------------: |
| `--context-file`   | [Context file](https://Singularity.com/docs/reference/cli-set-context#using-a-named-context-file) path and file name                      | string |                                                     |
| `--project-id`     | Project ID                                                                                                         | string | Only if your Singularity account has more than one project |
| `--protected-only` | If true, the list will be applied only to protected branches. Use `--protected-only false` to remove this setting. | string |                                                     |

#### Example

```bash
Singularity ip-allow add 192.0.2.3 --project-id cold-grass-40154007
```

### reset

This subcommand allows you to reset the list of IP addresses. You can reset to different IP addresses. If you specify no addresses, currently defined IP addresses are removed.

#### Usage

```bash
Singularity ip-allow reset [ips ...] [options]
```

#### Options

In addition to the Singularity CLI [global options](https://Singularity.com/docs/reference/Singularity-cli#global-options), the `reset` subcommand supports these options:

| Option           | Description                                                                                   | Type   |                      Required                       |
| ---------------- | --------------------------------------------------------------------------------------------- | ------ | :-------------------------------------------------: |
| `--context-file` | [Context file](https://Singularity.com/docs/reference/cli-set-context#using-a-named-context-file) path and file name | string |                                                     |
| `--project-id`   | Project ID                                                                                    | string | Only if your Singularity account has more than one project |

#### Example

```bash
Singularity ip-allow reset 192.0.2.1 --project-id cold-grass-40154007
```
